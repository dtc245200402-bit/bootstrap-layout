# Thực hành: Tạo layout trong Bootstrap

Bài làm sử dụng **Bootstrap 3.3.7** đúng theo tài liệu đề bài, gồm:

- Header “Online shopping mall” và ảnh minh họa bên phải.
- Navbar `navbar-inverse` có Glyphicons và menu tài khoản dạng dropdown.
- Nội dung chia cột bằng Bootstrap Grid: danh sách sản phẩm và sidebar.
- Giỏ hàng, ô tìm kiếm, danh mục hàng hóa và thẻ hỗ trợ.
- 6 sản phẩm hiển thị 3 sản phẩm mỗi hàng trên desktop, tự chuyển bố cục trên màn hình nhỏ.
- CSS tùy chỉnh nằm trong `poly.css`; hình ảnh SVG được lưu trong thư mục `images/`.

## Chạy thử

Mở `layout.html` bằng trình duyệt. Cần có kết nối Internet để tải Bootstrap 3.3.7 và jQuery từ CDN. Các ảnh minh họa là file SVG cục bộ nên không cần tải riêng.

## Đưa lên GitHub

Tạo repository mới, ví dụ `bootstrap-layout`, sau đó upload toàn bộ `layout.html`, `poly.css`, `README.md` và thư mục `images/`.
